## Purpose
This setup serves as a starting point for studying Git collaboration. Each member can clone this repository, create their respective `.html` file, and commit/push their page to learn collaboration workflows.

## How to use
1. Open the [index.html](file:///C:/Users/ADHIL%20CP/.gemini/antigravity-ide/scratch/git-collab-dashboard/index.html) in your browser.
2. Set this directory (`C:\Users\ADHIL CP\.gemini\antigravity-ide\scratch\git-collab-dashboard`) as your active workspace in the editor.
3. Every member should create their own HTML file in this directory (e.g., `adhil.html`, `advika.html`) and design their page.
